# PaperTCG-UI-Kit

**紙OCGの対戦動画を、初見の視聴者にもわかりやすくするための編集補助ツール**

## 1. このツールについて

PaperTCG-UI-Kitは、紙のOCG（オフィシャルカードゲーム）の対戦動画を、視聴者にとってわかりやすく編集するための補助ツールです。

対戦中に何が起きたのか。どの場面でカードの発動があったのか。

そうした履歴を動画上の時間と対応づけ、番号などの視覚的な手がかりとして映像に反映することで、対戦の流れを追いやすくすることを目指しています。

特に、事前知識のない視聴者でも、動画を一度見たときに「どこで何が起きたのか」を理解しやすくすることを重視しています。

## 2. 想定する使い方

本ツールは、主に紙OCGの対戦動画を編集する方に向けたものです。

- 発動履歴と動画上の時間を対応づける
- 発動があった場面に番号を表示する
- 番号を映像に焼き込み、動画として書き出す
- 既存の履歴や編集方法と組み合わせて利用する

本ツールだけですべての対戦履歴を自動判定することを目的としていません。編集者が必要な情報を映像に落とし込むための補助として利用できます。

## 3. 基本的な操作

1. 対戦動画を読み込む
2. 動画を確認しながら履歴を記録・編集する
3. 履歴に対応する番号の表示位置やタイミングを確認する
4. 番号を映像に焼き込んだ動画を書き出す
5. 書き出した動画を確認し、必要に応じて編集に利用する

## 4. 制約について

本ツールは試作版です。

対戦内容そのものを自動で理解・判定するものではなく、履歴の入力や映像への反映は編集作業の一部として扱います。

また、対戦動画の編集全体を置き換えるものではありません。既存の履歴や動画編集環境と組み合わせた利用も想定しています。

## 5. 目指していること

目指しているのは、情報を大量に表示することではありません。

対戦中の重要な出来事を、時間的に正確な位置へ、必要な視覚情報として刻むことです。

視聴者が複雑な対戦の流れを追いやすくなり、編集者がその情報を動画に反映する負担を減らす。その一歩を支えるツールを目指しています。

## 6. 感想・改善案について

試作品を使ってみた感想や、改善案を歓迎します。

特に、次の点について意見をいただけると助かります。

- 初めて見る人にとって、対戦の流れはわかりやすくなったか
- 番号の表示位置・大きさ・表示時間は適切か
- 編集時の操作でわかりにくい部分はないか
- 既存の履歴や動画編集の作業と組み合わせやすいか
- どのような機能や改善があれば、実際の編集で使いやすくなるか

すべての要望を実装できるとは限りませんが、実際の利用者の感想を今後の改善に役立てたいと考えています。

- 対戦動画の内容やカードの発動を自動判定するツールではありません。履歴の記録・編集と、映像への反映を補助する目的で使用してください。
- 書き出した動画は、公開・共有する前に、番号の表示タイミング、映像、音声が意図した状態になっていることを確認してください。
- 対戦動画、カード画像、音声、その他の素材を公開・再配布する場合は、それぞれの権利や利用条件を確認してください。
